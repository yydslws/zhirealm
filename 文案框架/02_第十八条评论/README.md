# 02｜第十八条评论：里面的人发现了你

## 这一部分的故事是什么？

一条评论提醒玩家凌晨两点后不要展开折叠内容。页面上的数量从17变成18。玩家点开后，一位没有头像、名字叫“用户不存在”的人说了一句明显是在对当前读者说的话。

从这一刻开始，玩家不再只是旁观一个旧故事。

## 呈现方式是什么？

**点击交互＋一次短暂文字异变＋可输入的评论对话。**

1. 静态提醒：“凌晨两点之后，不要点开折叠评论。”
2. 玩家看到入口时，故事时间进入02:00，折叠数量17变18。
3. 点击展开，第18条评论出现，旧评论仍然保留。
4. 点击“回复”，可以自由输入，也可以选一个建议问句。
5. 角色给出回复后，出现宿管私信通知，接入03。

这里不需要真的写满18条评论；编号代表折叠内容的叙事总量，首屏可只展示与当前剧情有关的几条。

## 关键示例

首次出现：

> 用户不存在：你终于点进来了。

建议问句：

> 你是谁？
> 你住在404吗？

固定首轮回复骨架：

> 我住过四楼。你先别问名字。有人会看到。

## 玩家动作与推进

首次展开只触发一次轻度污染，重复收起展开不累计惩罚。玩家暂时不聊天时，仍能通过出现的私信通知进入后续剧情。自由聊天用于探索角色，不要求玩家猜中某一句口令。

## 你后续要写什么？

夜间提醒、第18条评论、3个建议问句、首次固定回复、3–4条此时可见的旧评论、私信通知文字。

## 前端同学需要做什么？

实现数量替换、折叠展开、单条评论插入、回复框和通知提示。关键评论必须保持可读，不用持续闪烁承载线索。
