## 本阶段固定新增设定

- 06 三个结局共同前置固定为：`hasPublishedOwnAnswer=true`、`ownAnswerRegistered=true`、`ownAnswerId` 指向当前周目有效的署名“你”的回答卡、`endingSettled=false`。
- 发布前没有宿管关闭结局、用户不存在回首页结局或自己的回答删除结局；`P06_LOCKED_BEFORE_PUBLISH001` 是发布前兜底。
- A 结局固定为 `death_404`：发布后点击宿管站内“关闭此页”并确认。错误页显示“该回答不存在”只表示玩家不可见；回答仍保留，本轮绑定仍有效。
- B 结局固定为 `exit`：发布后在用户不存在会话点击固定话题 `P06_B_SUGGESTION_EXIT001`“怎样离开这里？”，获得“回到首页”入口并确认。用户不存在只知道临时回首页，不知道删除出口。
- B 的新增评论 `P06_B_AUTO_COMMENT001` 属于页面自动事件，落在署名“你”的回答卡下方。B 后问题回答数显示 119，高赞回答“南楼旧床板”的评论数保持 25，署名“你”的回答评论数变为 1。
- C 结局固定为 `delete`：发布后从自己的回答卡“更多→删除回答”并确认。确认后真实删除本轮自己的回答，解除本轮绑定。
- C 删除成功后必须清空本轮 `ownAnswerText`、`draftPreviewText`、`publishSnapshotText` 及任何可恢复成活动回答的正文副本；跨轮摘要只保留删除事实、结局和少量行为标记，不保存被删回答全文。
- C 删除成功后 `ownAnswerRegistered=false`，表示本轮登记已经解除。
- B 的固定话题“怎样离开这里？”计入对用户不存在的真实回复，写入 `hasRepliedUser404=true`，并可记录 06 阶段首次话题 `p06_exit`。
- 回答的周目归属必须在 05 发布成功时写入；06 只校验，不把未知旧 `ownAnswerId` 补成当前周目。
- 三个结局收束屏之间使用 `P06_CTRL_CONTINUE_ENDING001` 推进；第 3 屏后才开放“查看本轮记录”和“重新进入”。
- C 不要求 C5、全收集、信任值或任何聊天门槛。知道答案的玩家发布后可以直接删除。
- “但记录仍然存在”只指来访痕迹，不否定 C 的删除和解绑。
- 三结局互斥且一次结算。`endingSettled=true` 后不能覆盖 `endingId`、不能重复加 B 自动评论、不能再次删除或关闭。
- 真实关闭浏览器标签页或刷新只恢复本轮状态；不触发 A，不写结局，不增加周目。
- 只有结局完成后点击 `P06_CTRL_REENTER001`“重新进入”，才进入 07 新周目。刷新结局屏不增加周目。

## 结局事件与 07 记忆依赖

- `ending_event_death_404`：只由宿管站内关闭确认触发。07 可据此写“上次按宿管入口关闭后被留下”，不能把看过宿管私信或问过宿管当成相信她。
- `ending_event_exit`：只由用户不存在固定话题给出的回首页确认触发。07 可据此写“上次暂时离开，回答仍在”，不能写成玩家删除成功或死亡。
- `ending_event_delete`：只由自己的回答卡删除确认触发。07 可据此写“上次删除了那篇回答并解除本轮绑定”，不能让同一篇回答在新周目复活。

06 在结局确认成功时写入精简 `previousRun` 事实摘要。缺失信息写 `unknown`，不要让 07 用 NPC 闲聊摘要或 AI 生成内容补历史。`false` 只代表本轮明确没有发生。`previousRun` 不包含玩家回答全文；C 删除后 `previousRun.ownAnswerId` 写 `null`，新周目只能知道“删过并解绑”，不能恢复或重建那篇回答。

## 后续必须承接事项

- 07 新周目启动时应清空本轮线索、草稿、`ownAnswerId`、`ownAnswerDeleted`、`ownAnswerBindingActive`、`endingSettled` 等临时状态，只读取 `previousRun`。
- C 结局后新周目不能恢复上一轮那篇已删除的自己的回答，也不能从 `ownAnswerText`、草稿快照或发布快照恢复活动回答；如新轮玩家再次发布，应生成新的 `ownAnswerId`。
- A/B 结局后上一轮回答可作为残留痕迹被 07 以摘要方式引用，但不能自动当作新周目已发布回答。
- 07 对未见角色、未聊天、未看 C5、未确认具体结局或字段缺失的情况，必须使用中性未知文案。
- 09 前端交接需要保留一次性结算锁、B 自动评论落点、真实刷新续局、新周目只由“重新进入”触发等条件。
