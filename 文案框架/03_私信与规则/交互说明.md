# 03｜私信与规则：交互说明

本阶段承接 02 的宿管私信通知。玩家进入私信后获得宿管开场、宿管发来的三条规则卡、六条“已收集的提醒”汇总、消息详情和用户不存在的旧截图入口。只阅读规则、打开私信、发送消息、查看详情或点开截图入口，都不能被解释为“相信宿管”或“选择阵营”，也不会触发死亡。

## 承接状态

| 来自前序的状态 | 需要满足的值 | 03 的处理 |
|---|---:|---|
| `gameTime` | `02:00` | 私信侧栏显示叙事时间 `02:00`；不读取现实系统时钟 |
| `pmDormManagerNotified` | `true` | 允许从通知或消息入口进入本阶段 |
| `phase03Available` | `true` | 右侧或顶部私信入口保持可用 |
| `hasSeenUser404Comment` | `true` | 允许私信列表出现“用户不存在”会话 |
| `hasRepliedUser404` | 任意 | 不影响进入 03；未回复也会看到宿管私信和规则卡 |
| `user404FirstReplyKind` | 任意或 `null` | 03 中所有对用户不存在的非空发送和建议话题都继续沿用该字段；只在值为 `null` 时写入 |

若玩家从 02 的“稍后再看”返回正文或评论区，消息入口仍保留未读态。点击后进入同一条宿管会话，不重复创建消息。

## 新增状态字段

| 字段 | 初值 | 写入时机 | 是否跨轮 |
|---|---:|---|---|
| `p03MessagesOpen` | `false` | 点击 `P02_CTRL_OPEN_PM001` 或全局消息入口后改为 `true`；点击 `P03_CTRL_CLOSE_MESSAGES001` 后改为 `false` | 否 |
| `activeMessageThread` | `null` | 进入 03 时写入 `dorm_manager`；切换会话时写入 `dorm_manager` 或 `user404` | 否 |
| `hasSeenDormOpening` | `false` | `P03_DORM_MSG_OPENING001` 首次展示后改为 `true` | 结局结算时可写入跨轮摘要 |
| `hasSeenDormRuleCard` | `false` | `P03_RULE_CARD_TITLE001` 首次展示后改为 `true` | 本轮内保存 |
| `hasSeenCollectedRulesSummary` | `false` | `P03_COLLECTED_RULES_TITLE001` 首次展示后改为 `true` | 本轮内保存 |
| `discoveredRules` | 沿用前序，通常为 `[]` | 宿管规则卡展示后加入 `R2`、`R4`、`R6`；已收集提醒汇总展示后合并加入 `R1`—`R6` | 本轮内保存 |
| `ruleSourceViewedIds` | `[]` | 点击任一条规则的 `P03_RULE_PANEL_BACK_TO_SOURCE001` 后加入对应 `R1`—`R6` | 本轮内保存 |
| `hasOpenedDormMessageDetail` | `false` | 点击 `P03_CTRL_OPEN_DETAIL001` 后改为 `true` | 本轮内保存 |
| `hasSeenC3` | `false` | `P03_MESSAGE_DETAIL_DORM001` 展示后改为 `true` | 本轮内保存 |
| `discoveredClues` | 沿用前序，通常含 `C1` | 消息详情展示后加入 `C3` | 本轮内保存 |
| `hasChattedDormManager` | `false` | 玩家向宿管发送非空消息或点击宿管建议话题后改为 `true` | 结局结算时可写入跨轮摘要 |
| `dormManagerFirstTopic` | `null` | 首次向宿管发送消息时写入 `rules_source`、`user404_warning`、`time_anomaly` 或 `free_input` | 结局结算时可写入跨轮摘要 |
| `hasOpenedUser404ThreadFromP03` | `false` | 切换到用户不存在会话后改为 `true` | 结局结算时可写入跨轮摘要 |
| `hasAskedUser404ForScreenshot` | `false` | 点击旧截图建议话题后改为 `true` | 本轮内保存 |
| `user404FirstP03Topic` | `null` | 首次向用户不存在发送 03 阶段消息时写入 `old_screenshot`、`dorm_manager`、`dangerous_rule` 或 `free_input` | 结局结算时可写入跨轮摘要 |
| `oldScreenshotEntryAvailable` | `false` | 打开 03 后展示固定旧截图入口时改为 `true` | 本轮内保存；04 承接 |
| `hasOpenedOldScreenshotEntry` | `false` | 点击 `P03_CTRL_OPEN_SCREENSHOT001` 后改为 `true` | 本轮内保存；04 承接 |
| `phase04Available` | `false` | `oldScreenshotEntryAvailable=true` 后改为 `true` | 本轮内保存 |

少量跨轮摘要只在结局完成时统一写入。刷新或关闭真实浏览器不算结局，不得把这些本轮字段直接当作下一周目记忆。

`hasRepliedUser404` 是 02 已定义字段，03 不另设同义变量。玩家在 03 中点击任一用户不存在建议话题，或向用户不存在发送任意非空消息，都必须写入 `hasRepliedUser404=true`。`user404FirstReplyKind` 也沿用 02 字段，只在当前值为 `null` 时写入，避免覆盖 02 的首次回复记录。

## AI 与断网约束

- 宿管和用户不存在各三个建议话题必须走固定文案，断网也能推进到规则卡、C3 详情和旧截图入口。
- 自由输入可以调用 AI，但 AI 只能在当前角色知识范围内改写语气。宿管可重复强调“按规定、别回复、关闭页面”；用户不存在可强调“看来源、看时间、看编辑记录”。
- AI 不能新增或修改 R1—R6，不能发放 C2 截图正文、C4 编辑正文、C5 前人留言，不能告诉玩家删除回答是出口，不能判定玩家相信了谁。
- 异步对话失败时显示对应固定提示，不阻挡查看规则、消息详情或旧截图入口。

## 前端呈现要求

- 私信侧栏应像普通站内消息：会话列表、消息气泡、详情入口、未读状态和关闭按钮。
- 宿管显示身份承接 02 的“明德楼宿管”，可在 UI 中称“宿管阿姨”，但系统角色 ID 统一用 `dorm_manager`。
- 规则卡每条独立可点，来源可回看。玩家不需要按顺序看完所有规则才能进入 04。
- C3 只由 `P03_MESSAGE_DETAIL_DORM001` 定义并发放：发送 `01:56`、进入 `01:57`、送达 `02:00`。这些都是叙事时间，不能用现实时间替换。
- 旧截图入口在 03 固定开放，截图内容和线索 `C2` 的具体展示由 04 接续，避免出现第二套截图文本。
