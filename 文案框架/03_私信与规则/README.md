# 03｜私信与规则：谁在保护你？

## 这一部分的故事是什么？

“宿管阿姨”主动发来私信，语气像在处理普通校园问题。她知道玩家在看四楼的帖子，并发来夜间管理规定。规定中的一条要求玩家不要回复“用户不存在”。

与此同时，那个用户说自己有一张旧截图，可以证明404存在。玩家第一次遇到有实际后果的信息冲突：遵守看似权威的规则，会不会失去唯一的证人？

## 呈现方式是什么？

**可交互私信侧栏＋静态规则卡＋可查看的消息详情。**

- 宿管主动来信，玩家可以自由回复或使用建议问句。
- 规则以一张简短的“四楼夜间管理规定”出现；另有评论区补充，标明各自来源。
- 点击规则可以回到来源消息，便于对照。
- 消息详情显示发信时间。它早于本轮页面进入时间，形成C3。
- 用户不存在的旧截图入口在此开放，调查进入04。

## 关键示例

宿管开场：

> 同学，你是不是在看四楼那个帖子？

宿管劝阻：

> 名字都没了的人，你还回他做什么？按规定来就行。

用户不存在：

> 我有改掉之前的截图。你可以自己看。

## 玩家动作与推进

阅读规则卡即可获得规则文字，不等于知道真假。回复任一角色都不会立刻因“选错人”死亡。只有最终执行危险操作才进入相应结局，给玩家核实和改变判断的空间。

六条规则的来源、真假与证据见 [规则与线索骨架](../04_调查与证据/规则与线索骨架.md)。规则面板只呈现“原文＋来源＋相关证据”，不替玩家标出正确答案。
