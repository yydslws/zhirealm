# 09｜统一状态与存档规范

## 顶层结构

```text
saveVersion, saveRevision
run, scene, phase
gameTime, timeStopped, pollution
currentRun { ... }
previousRun { ... } | null
aiSession { ... }
```

`currentRun` 只描述当前轮；`previousRun` 只保存上一轮已结算事实。不得把 A/B 残留回答渲染成当前轮回答，也不得从 C 的摘要恢复已删除正文。

|---|---|---|

## 发布快照

草稿由 `P05_DRAFT_BASE001` 加玩家实际看过的 C2/C4/C3/C5 插句组成。玩家打开确认框时冻结 `publishSnapshotText`；确认期间新取得的证据不能悄悄进入快照。成功发布原子写入：

```text
hasPublishedOwnAnswer=true
ownAnswerRegistered=true
ownAnswerId=<new unique id>
ownAnswerRunId=run
ownAnswerText=publishSnapshotText
ownAnswerVisible=true
ownAnswerDeleted=false
ownAnswerBindingActive=true
timeStopped=true
gameTime="02:07"
pollution=3
phase06Available=true
```

问题回答数从 118 变 119；“南楼旧床板”的评论数保持 25；新回答评论数为 0。

## 结局原子提交

| 结局 | 当前回答 | 绑定 | 计数 / 附加结果 |
|---|---|---|---|
| A `death_404` | 保留但对玩家不可见 | 保持 | 问题回答事实仍为 119；错误页不等于删除 |
| B `exit` | 保留且可见 | 保持 | 问题回答 119；自己的回答下增加唯一自动评论，评论数 1 |
| C `delete` | 真正删除 | 解除 | 问题回答回到 118；清空活动正文、草稿和发布快照副本 |

成功提交必须一次写入 `endingId`、`endingEventId`、结果字段、`endingSettled=true`、`endingScreenIndex=1` 和冻结的 `previousRun`。失败时全部保持提交前状态。已结算后的延迟回调和重复确认只恢复既有结局。

## previousRun 最小事实摘要

保存：上一轮编号、完成时间 02:07、结局及事件 ID、是否发布、A/B 的残留回答 ID 或 C 的 null、登记/删除/保留/绑定结果、三种结局动作布尔、B 自动评论事实、见过和回复用户不存在、宿管开场/聊天、C2—C5 已读、草稿解锁来源、三角色 firstTopic、`hasAskedAuthorInP04`。不保存自己的回答全文、草稿全文、AI 新事实或把自由对话摘要当行为事实。

每个历史布尔只能是 `true`、`false`、`unknown`：明确发生为 true，明确未发生为 false，旧档缺失或读取失败为 unknown。`lastConversationSummary` 只保留玩家所问主题与角色语气，用于对话连贯，不参与 07 条件判定。

## 新一轮重置

只有结局第 3 屏的 `P06_CTRL_REENTER001` 可执行：先冻结 `previousRun`，再使 `run+1`，随后重建干净的 `currentRun`。保留上一轮摘要和 A/B 的“痕迹事实”；不保留活动回答、当前轮线索/草稿/污染/停钟/结局锁。C 的回答与正文绝不恢复。R4 在二周目只增加“适用旧宿舍走廊”的范围说明，真假不随机变化。

清除记忆只删除 `previousRun`、恢复原始差异文本并重置 `p07LoadedPreviousRun`；不改变 `run`，不清当前轮进度，不把 `p07MemoryCleared` 永久跨轮保存。

## 存档迁移与校验

- 缺少 `saveVersion` 的旧档先迁移；能证明的事实照录，不能证明的历史字段写 unknown。
- `ownAnswerRunId != run`、回答作者不是“你”、C 后仍有活动正文、`endingSettled=true` 却无唯一结局，均视为冲突存档并阻止危险操作。
- 以 `saveRevision` 做比较并交换；同一动作带稳定 `actionId`，保证插入评论、发布、B 自动评论、删除、结算和重新进入各执行一次。
- 真实刷新/关闭只保存和恢复当前状态，不写 `previousRun`，不增加 `run`。
