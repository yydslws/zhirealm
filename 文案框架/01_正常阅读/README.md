# 01｜正常阅读：一栋没有404的宿舍楼

## 这一部分的故事是什么？

玩家读到一位毕业生回忆大一生活：自己住四楼，403隔壁是405。大家用“建筑编号习惯”解释这个缺口。后来有人追问404，第二天就不再出现在同学的聊天中，答主只记得他“好像退学了”。

这段不解释超自然原因，只留下一个具体、可记住的矛盾：房间编号少了一个，大家的记忆也少了一个人。

## 呈现方式是什么？

**静态阅读为主，滚动和展开长回答为辅。**

- 顶部：问题标题、话题、关注与回答数。
- 主体：高赞回答，分成日常背景、编号缺口、消失的同学三个短段。
- 底部：普通评论。建筑解释、校园回忆、轻微玩笑混排。
- 阅读到评论区后，露出夜间提醒和折叠评论入口，接入02。

## 玩家动作与推进

进入页面即可阅读。展开回答或读到编号段落时，记录已见线索C1。页面内的故事时间随剧情进入02:00，不依赖现实时间，也不要求玩家等待。

## 关键示例

问题标题：

> 有没有什么事情，是你后来才发现不对劲的？

回答开头：

> 大一的时候，我住在学校最旧的那栋宿舍楼。
> 我们住四楼。403的隔壁是405。
> 这件事本身没什么，奇怪的是，我现在找不到那张合照里的第四个人了。

普通评论：

> 老楼改过房间吧，我们学校还有两个307。

## 你后续要写什么？

1个问题标题与简短补充、1篇约450–650字回答、5–7条普通评论、1条夜间提醒。普通评论可以营造人群感，但不都承担线索任务。

## 前端同学需要做什么？

做正常问答页、长回答展开和评论区；保留“编辑记录”入口但不高亮。此时不需要全屏黑化、弹出规则说明或角色介绍。
