# 01｜正常阅读：交互说明

本阶段只负责正常问答页和首次异常入口。页面保持普通社区观感，不出现全屏故障、规则面板、私信侧栏或第 18 条评论正文。第 18 条评论由 02 接续插入。

## 初始状态字段

| 字段 | 初值 | 写入时机 | 是否跨轮 |
|---|---:|---|---|
| `scene` | `question` | 进入页面时 | 否 |
| `gameTime` | `01:57` | 进入页面时展示 `P01_TIME001` | 否 |
| `pollution` | `0` | 进入页面时 | 否 |
| `answerExpanded` | `false` | 点击阅读全文后改为 `true` | 否 |
| `hasReadP01Answer` | `false` | 正文滚动到 `P01_ANSWER001` 末段或点击阅读全文后改为 `true` | 否 |
| `discoveredClues` | `[]` | 看到编号段落后加入 `C1` | 本轮内保存 |
| `hasSeenC1` | `false` | 看到“403的隔壁就是405”后改为 `true` | 否 |
| `visibleCommentIds` | `P01_COMMENT001`—`P01_COMMENT006`、`P01_NIGHT_NOTICE001` | 评论区出现时写入 | 否 |
| `foldedCommentCount` | `17` | 初次渲染折叠入口 | 否 |
| `nightNoticeVisible` | `false` | 滚动到评论区底部后改为 `true` | 否 |
| `p01ReadyForPhase02` | `false` | `gameTime` 变为 `02:00` 且夜间提醒可见后改为 `true` | 否 |

## 交互表

| 动作 / 入口 | 前置条件 | 文案 ID | 成功反馈及状态结果 | 取消 / 重复 / 返回行为 |
|---|---|---|---|---|
| 进入问题页 | 首轮或重新进入本阶段 | `P01_Q001`、`P01_Q002`、`P01_TOPIC001`、`P01_META001`、`P01_TIME001` | `scene=question`，`gameTime=01:57`，`pollution=0` | 刷新只恢复本阶段已读状态，不触发结局或污染 |
| 点击关注问题 | 无 | `P01_CTRL_FOLLOW` | 显示 `P01_TOAST_NORMAL_SAVE`，可把 `questionFollowed=true` | 再点取消关注，仅改普通 UI 状态，不影响剧情 |
| 点击阅读全文 | 回答卡未展开 | `P01_CTRL_EXPAND_ANSWER`、`P01_ANSWER001`、`P01_ANSWER_TAIL001` | `answerExpanded=true`，正文完整显示 | 再点 `P01_CTRL_COLLAPSE_ANSWER` 收起，不清除已读记录 |
| 阅读到编号段落 | `P01_ANSWER001` 可见 | `P01_ANSWER001` | 静默加入线索 `C1`，`hasSeenC1=true`；正常阅读阶段不弹调查提示，异常后回看可显示 `P01_TOAST_C1` | 重复滚动不重复弹提示；`C1` 只记录一次 |
| 点击赞同 / 收藏 | 回答卡可见 | `P01_CTRL_VOTE`、`P01_CTRL_COLLECT` | 更新按钮选中态与本地计数；收藏显示 `P01_TOAST_NORMAL_SAVE` | 重复点击只切换普通 UI，不影响剧情 |
| 点击评论按钮 | 回答卡可见 | `P01_CTRL_COMMENT`、`P01_EMPTY_REPLY` | 定位普通评论列表；自由输入入口在02的异常评论下开放，不推进主线 | 重复点击只定位，不产生玩家评论 |
| 滚动到评论区 | 正文下方进入视口 | `P01_COMMENT001`—`P01_COMMENT006` | `scene=comments`，展示普通评论 | 返回正文不重置评论状态 |
| 夜间提醒进入视口 | 评论区底部可见 | `P01_NIGHT_NOTICE001` | `nightNoticeVisible=true`，页面时间从 `P01_TIME001` 切换为 `P01_TIME002` | 重复进入不重复写入；时间保持 `02:00` |
| 折叠入口显示 | 夜间提醒可见前 | `P01_FOLDED_ENTRY001` | 展示“展开 17 条评论” | 入口进入视口即执行下一行数字变化；若在变化完成前点击，同一动作先完成02:00与18条替换，再交给02首次展开，不显示空占位 |
| 折叠入口数字变化 | `gameTime=02:00` 且 `nightNoticeVisible=true` | `P01_FOLDED_ENTRY002` | `foldedCommentCount=18`，`p01ReadyForPhase02=true` | 数字只变化一次；后续点击交给 02 处理 |
| 点击查看编辑记录 | 本阶段任意时刻 | `P01_CTRL_EDIT_HISTORY` | 打开 `P01_HISTORY_PREVIEW` 元信息弹层；不显示历史正文，04在首次异常后接管详情入口 | 点击 `P01_RETURN_ANSWER` 关闭弹层；不发放 `C4` |
| 点击写回答 | 本阶段任意时刻 | `P01_CTRL_ANSWER` | 显示 `P01_DRAFT_EMPTY` 与 `P01_RETURN_ANSWER`；不要求登录，不生成“你的回答”草稿 | 取消后无剧情后果；05 才开放自动草稿 |

| 点击分享 | 回答卡可见 | `P01_CTRL_SHARE` | 仅复制当前体验页链接；成功显示 `P01_SHARE_OK`，失败显示 `P01_SHARE_FAIL` | 不发布、不发送给其他人、不推进剧情 |

## 前端呈现要求

- 问答页应像普通社区：白底、常规头像、赞同数、回答编辑时间、评论列表、折叠评论入口。
- `P01_ANSWER_META001` 必须显示“当前为第 5 次编辑版本”，但本阶段不解释其异常含义。
- `C1` 只由 `P01_ANSWER001` 的编号段落触发；不要把“404 存在”提前写进提示。
- 页面内时间是叙事时间，不读取现实系统时间。首轮进入显示 `01:57`，评论区触发显示 `02:00`。
- 断网或 AI 不可用不影响本阶段阅读，所有内容均为固定文案。
