# 04｜调查与证据：有人正在修改过去

## 这一部分的故事是什么？

玩家拿到旧截图，发现过去的评论明确提过404；当前答主却坚称自己从没住过404。再打开编辑记录，玩家看到房间、同学名字和第一人称叙述被逐次改掉。

重点是让玩家从“相信谁的语气”转向“检查谁的话与证据一致”。答主的错误记忆可以被理解，宿管的主动关心则越来越可疑。

## 呈现方式是什么？

**主动调查交互＋固定证据文本＋与证据相关的NPC对话。**

| 入口 | 展示的故事材料 | 方式 |
|---|---|---|
| 原回答 | 403直接跳到405 | 静态正文，可回看 |
| 用户不存在的“查看旧截图” | 曾经存在的404与旧评论 | 点击展开静态档案卡，首版可用文字重现 |
| 宿管消息详情 | 发信比玩家进入页面更早 | 点击显示时间信息 |
| “编辑记录” | 五次编辑如何抹去同一段经历 | 弹层列出简短旧版本，不需要完整版本对比工具 |
| 旧记录中的隐藏评论 | 前人如何尝试离开，留下关于回答的提示 | 点击展开固定留言 |
| 答主头像或“询问答主” | 当前说法与旧文本发生矛盾 | 可交互对话 |

## 关键示例

旧截图：

> 404那位同学还在吗？他的床今天怎么空了？

答主：

> 404？我一直记得住403。你是不是看错回答了？

编辑记录：

> 早期版本：我们四个人住在404。
> 第五次编辑后：我们三个人住在403。

前人留言C5：

> 关掉以后，我又回到了这里。后来我才明白：只要“我的回答”还在，它就还能找到我。

## 玩家动作与推进

- C1—C4是基础调查材料；获得C2或C4后即可出现05的草稿提示，不要求读完全部档案。
- C5藏在编辑记录的旧评论入口中；无需二周目或特定聊天措辞，首轮就能找到。
- 基础证据可以任意次序查看；错过一条后仍能返回。
- 证据由固定入口提供，NPC可以解释、误导或催促，但不能临时创造新的通关事实。

## 你后续要写什么？

5条证据原文、5次编辑的关键短句、每条证据的来源标注、答主前后两种说法、前人留言。具体关系见 [规则与线索骨架](规则与线索骨架.md)。

## 前端同学需要做什么？

提供正文、截图卡、消息详情和编辑记录弹层；证据可收纳在一个简单的“已查看记录”区域。无需额外做地图、背包或连线推理小游戏。
