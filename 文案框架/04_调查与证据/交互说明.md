# 04｜调查与证据：交互说明

本阶段承接 03 的旧截图入口和规则面板。玩家通过固定入口查看证据、对照事实、询问三个 NPC。NPC 可以解释、推诿或推动玩家去点固定材料，但不能临时发放线索、改变规则、判定阵营或触发结局。查看 C2 或 C4 后开放 05 草稿入口；玩家仍可返回继续调查。

## 承接状态

| 来自前序的状态 | 需要满足的值 | 04 的处理 |
|---|---:|---|
| `gameTime` | 通常为 `02:00` | 首次展示 C2、C4 或调查首页时变为 `02:07`，之后保持 `02:07`；`timeStopped=false` |
| `pollution` | 通常为 `1` | 首次进入调查展示时固定提升到 `2`；重复查看不累加 |
| `discoveredClues` | 通常含 `C1`，可能含 `C3` | 04 追加 `C2`、`C4`、`C5`；C1/C3 只引用前序已定义正文 |
| `discoveredRules` | 通常含 `R1`—`R6` | 04 只更新规则面板中的“已见证据”，不重写规则原文 |
| `oldScreenshotEntryAvailable` | `true` | 允许从 03 的旧截图入口进入 C2 |
| `phase04Available` | `true` | 调查入口常驻，可从私信、规则来源或答主卡片进入 |
| `hasOpenedDormMessageDetail` / `hasSeenC3` | 任意 | 若未看过 C3，04 可显示回看入口；C3 正文仍由 03 定义 |

若玩家从 01 的编辑记录入口返回，异常前只看元信息；04 只有在 `phase04Available=true` 后才接管完整编辑记录。

跨轮摘要仍只在结局完成时写入。刷新或真实关闭浏览器只是恢复本轮进度，不增加周目，不把未完成调查写成二周目经历。
