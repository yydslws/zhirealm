# 07｜二周目记忆：网页没有忘记

## 这一部分的故事是什么？

玩家重新进入，同一个问题、同一篇宿舍往事，起初看起来一切正常。但上一轮的证人改变了称呼，规则上多了一行批注，宿管的口气也发生变化。玩家意识到：重来只重置了页面，没有完全抹掉来过的痕迹。

## 呈现方式是什么？

**按上一轮记录替换静态文字＋可交互的NPC回访。** 复用已有页面和组件，不新增第二套流程。

| 变化位置 | 有什么故事变化 | 呈现方式 |
|---|---|---|
| 第18条评论 | 角色认出曾经见过的玩家 | 替换首次出现的短句 |
| R4附近 | 前人批注指出它只讲宿舍走廊，不能带人离开网页 | 原规则下方多一行手写感文本；原文可读 |
| 私信或用户不存在的回复 | 角色根据上次真实结局提起一次具体选择 | 固定回忆句＋继续聊天 |

## 关键示例与条件

上一轮见过用户不存在：

> ……你为什么又回来了？

上一轮没有见过他：

> 这篇回答里，有你留下的记录。

上轮按宿管指示进入A：

> 你还是按她说的关掉了。后来这里多了一位住户。

上轮进入B：

> 你走以后，那篇回答一直挂在这里。

上轮进入C：

> 回答已经没了。我还记得有人删过它。

R4补充批注：

> 不敲门，只能让你走过那条走廊。你现在被留在的是网页里。

## 玩家动作与推进

完整结局后点击“重新进入”才算新周目；普通刷新只是继续当前局。对话只引用已保存的行为，不凭空说玩家上局信了谁、问过什么或怎么死亡。

当前框架采用固定规则加新批注，不在第二周目随机改变规则真假。原技术文档中“上一次你就是因为相信这条死的”这类句子，需要实际死因支持才可使用，本版不作通用台词。

## 你后续要写什么？

1组见过／没见过角色的开场、3组结局回忆、1条规则批注、每位NPC各1–2句二周目态度变化。沿用首轮主线，重点呈现记忆。

## 前端同学需要做什么？

保存周目、前次结局、是否见过用户不存在、是否执行宿管指令。根据记录选择对应文案；“继续游戏”“重新进入”“清除记录”需区分，清除记录会删除跨周目记忆。
