# 07｜二周目记忆：memory

## 工作摘要

本阶段完成 07 的玩家可见文案、交互说明和交接记录。只编辑 `文案框架/07_二周目记忆` 目录，保留原 README。

## 本阶段判断

- 07 的核心不是“run 大于 1 就认识玩家”，而是读取 06 在结局确认成功时写入的 `previousRun`。
- `true` / `false` / `unknown` 必须三态分开。`false` 可写明确没发生；`unknown` 只能写记录不完整。
- A/B/C 回忆必须和 06 结局事件一致：A 是宿管站内关闭后回答仍在；B 是用户不存在临时回首页后回答仍在；C 是删除自己的回答并解绑。
- R4 二周目只加范围批注，不改变真假，不使用技术规格旧示例里的“因为相信这条死了”。
- C 之后不能恢复被删回答正文，只能显示来访痕迹或已删除占位。
- 用户不存在仍不知道删除出口；他可以观察到“有人删过”，不能说出完整原理。
- B 的自动评论是页面事件，不是玩家发言，不得作为普通对话历史。

## 输出文件

- `完整文案.md`：定义 07 的替换文案、NPC 回访、R4 批注、继续/清除/存储失败反馈。
- `交互说明.md`：定义进入条件、新轮重置、三态、替换优先级、三结局互斥、首次话题映射、清除记录流程。
- `交接记录.md`：列明依赖、字段、设定、自审和给 08/09 的注意事项。
