## 本阶段固定新增设定

- 07 只在 06 第三屏后点击“重新进入”时启动。真实刷新、关闭标签、恢复结局屏或继续未完局都不增加周目。
- 新周目重置当前轮线索、规则来源、草稿、发布状态、回答绑定、结局状态和操作锁；保留 `previousRun`，并在进入 07 时复制为本轮只读的 `p07LoadedPreviousRun`。
- `previousRun.completed=true` 且结局 ID 与事件、动作布尔值匹配时，才允许展示具体 A/B/C 回忆。
- `false` 表示明确没发生；`unknown` 表示字段缺失、旧存档缺项、读取失败或枚举不认识。07 对二者使用不同文案。
- 第 18 条评论首句有三种替换：见过 `P07_COMMENT18_SEEN001`、没见过 `P07_COMMENT18_NOT_SEEN001`、未知 `P07_COMMENT18_UNKNOWN001`。
- 用户不存在回复过时，再按 `firstTopic.user404` 选择具体回忆；B 结局固定话题 `p06_exit` 可归到问过出口类回忆。
- R4 只追加范围批注 `P07_RULE_R4_NOTE001` 或旧记录不足批注 `P07_RULE_R4_NOTE_UNKNOWN001`，不改原文、不随机改真假，不写“因为信 R4 所以死”。
- A 回忆只说玩家按宿管站内入口关闭后，回答仍在、绑定未解除；不能把看过宿管私信或问过宿管写成 A。
- B 回忆只说玩家通过用户不存在临时回首页，回答仍在，B 自动评论是页面事件，不是玩家发言。
- C 回忆只说玩家删除了自己的回答并解绑；已删正文不恢复，不复述为新轮活动回答。用户不存在可说“还记得有人删过”，但仍不知道删除出口。
- 三位 NPC 各有 1–2 句态度变化，且每次只选一种结局态度，避免同一 NPC 同时说 A/B/C、已聊/未聊。
- 清除记录有入口、确认、取消、成功和失败文案。清除的是跨周目来访记忆，不替代 C 删除，也不能恢复已删除回答。
- 增加读取失败、保存失败、旧回答归属缺失的中性反馈，旧存档不完整时不补写玩家经历。
